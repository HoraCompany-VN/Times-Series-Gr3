# Time Series Analysis

## Overview
Analysis of daily minimum temperatures in
Melbourne, Australia (1981–1990).
Link: https://www.kaggle.com/datasets/vipullrathod/daily-min-temperatures

## Dataset
Daily Minimum Temperatures in Melbourne.

## Analysis
- Time Series Visualization
- ACF and PACF Analysis
- White Noise Analysis
- Seasonal Decomposition (STL)
- Missing Value Handling
- Outlier Detection

## Project Structure
- data/raw - Original dataset
- data/processed - Clean dataset
- Task/ - Desribe lab, include: Lab1_descript.md, process.md, report.docx
- src/ - Stored code - Lab1_code.ipynb, proc_data.py

pip install -r requirements.txt
